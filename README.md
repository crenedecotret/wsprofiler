# wsprofiler

PySide6 desktop GUI that wraps the Argyll CMS color-profile pipeline (targen → printtarg → chartread → colprof).

## Installation

### Prerequisites

- **Python 3.10+**
- **Argyll CMS binaries** (`targen`, `printtarg`, `chartread`, `colprof`, etc.) installed and on your `PATH`

### Linux/macOS

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m wsprofiler
```

### Windows

1. **Install Python 3.10+** from [python.org](https://python.org) (check "Add Python to PATH" during install)

2. **Download and install Argyll CMS** for Windows from [argyllcms.com](https://www.argyllcms.com/):
   - Download the Windows zip distribution
   - Extract to a folder like `C:\Argyll_V3.x.x\bin`
   - Add this `bin` folder to your system PATH:
     - Open System Properties → Advanced → Environment Variables
     - Edit "Path" under System variables
     - Add the path to Argyll's `bin` directory

3. **Install wsprofiler**:

```powershell
# Create and activate virtual environment
python -m venv .venv
.venv\Scripts\activate

# Install the package
pip install -e .

# Run the application
python -m wsprofiler
```

**Note:** On Windows, the application uses `pywin32` for console interaction with ArgyllCMS tools. This is automatically installed as a Windows-only dependency.

## Building Standalone Executables

### Local Build

To build a standalone executable locally (requires Python and pip):

```bash
# Install build dependencies
pip install -e ".[build]"

# Build executable
pyinstaller wsprofiler.spec --clean --noconfirm
```

The executable will be created in the `dist/` directory:
- **Linux**: `dist/wsprofiler` (single binary)
- **Windows**: `dist/wsprofiler.exe` (single executable)

### Automated Builds with GitHub Actions

This repository includes GitHub Actions workflows that automatically build executables for Linux and Windows on every push to `main`/`master` and for every tag starting with `v`.

**To set up automated builds:**

1. Create a GitHub repository at https://github.com/new
   - Repository name: `wsprofiler`
   - Make it public or private as desired

2. Push your code to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/crenedecotret/wsprofiler.git
   git push -u origin main
   ```

3. The GitHub Actions workflows will automatically:
   - Build Linux executable on every push to `main`/`master`
   - Build Windows executable on every push to `main`/`master`
   - Create GitHub Releases with both executables when you push tags like `v1.0.0`

4. **Download executables**:
   - Go to your repository's **Actions** tab to see build progress
   - Download artifacts from completed workflows
   - Or create a release by pushing a tag: `git tag v1.0.0 && git push origin v1.0.0`

**Note**: The executables bundle Python and PySide6, making them ~50-100MB. Users don't need Python installed to run them.

## Features

- **Wizard shell** mirroring the targen → printtarg → chartread → colprof pipeline.
- **Measurement page**: instrument sidebar, status header, `.ti2` loader, live chart grid, and log console.
- **.ti2 parsing** via a lightweight CGATS reader; supports RGB and CMYK charts and groups patches by page/strip.
- **Chart visualization** using `QGraphicsView` with a highlight overlay that follows the strip index reported by `chartread`.
- **chartread integration**: the UI spawns `chartread <basename>` in the chart directory, streams stdout/stderr, reacts to "Reading row" prompts, and sends calibration keystrokes.

## Sample data

A minimal `.ti2` file lives in `assets/sample/sample_chart.ti2` so you can verify rendering without needing to generate a full chart first. Use **Measurement → Load .ti2…** to pick another file generated by `printtarg`.

## Status

Early prototype: wizard shell, `.ti2` parsing, chart visualization, and `chartread` session handling are implemented. Pipeline generation (targen/printtarg) and ICC build (colprof) steps are functional.
