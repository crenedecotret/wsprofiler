# Plan: Add `.wsp` Save/Load to Main Wizard

## Overview

Implement save/load functionality for the 3-page main wizard (`Wizard`), using `.wsp` extension (distinct from the two-step wizard's `.wsp2`).

Two save behaviors:
1. **Auto-save silently** after profile creation — packages all files (`.ti1`, `.ti2`, `.ti3`, `.tiff`, `.icc`) into `{target_name}.wsp` in the target directory.
2. **Manual save/load buttons** on `MeasurementPage` — lets users save progress (`.ti1`, `.ti2`, `.tiff`, `.ti3` if exists) and close the app while the printed target dries.

The `.wsp` format uses the same zip+JSON manifest as `.wsp2` but with a simpler `SimpleSnapshot` dataclass. It is archive-only for now but extensible for future resume support.

## Phase 3: Add Save/Load Buttons to MeasurementPage

**File:** `wsprofiler/ui/pages/measurement_page.py`

1. Add `self.save_btn = QPushButton("Save Session")` and `self.load_btn = QPushButton("Load Session")` to the existing `button_row`.

2. Implement `_on_save()`:
   - If `chartread` is active, stop it first and wait for `measurementStopped` signal (same pattern as `TwoStepWizardDialog._on_save_session`).
   - Collect files:
     - `.ti2`: `self._current_chart_path`
     - `.ti1`: `self._current_chart_path.with_suffix(".ti1")`
     - `.ti3`: `self._current_chart_path.with_suffix(".ti3")` (if exists)
     - `.tiff` pages: use `find_tiff_pages(self._current_chart_path)`
   - Call `SimpleSessionController.save()` with target dir = `self._current_chart_path.parent`, target name = `self._current_chart_path.stem`.
   - Show confirmation in status label or console.

3. Implement `_on_load_session()`:
   - Open `QFileDialog` filtered for `*.wsp`.
   - Call `SimpleSessionController.load(path, output_dir=path.parent)`.
   - Find `"ti2"` in resolved files, call `self.load_ti2(ti2_path)`.
   - Existing `_load_file()` will automatically discover and load any `.ti3` in the same directory.

4. Button visibility:
   - `save_btn`: visible when `self._current_chart_path is not None`
   - `load_btn`: always visible (disabled during active measurement session)

## Phase 4: Hook Auto-Save in Wizard

**File:** `wsprofiler/ui/wizard.py`

1. Connect `ProfilePage.profileGenerated` to new `_on_profile_generated(icc_path: Path)` slot.

2. In `_on_profile_generated`:
   - Get target path from `GeneratePage.generated_target_path` (add this property in Phase 5).
   - If no target, skip silently.
   - Collect all files:
     ```python
     file_paths = {}
     if ti2.exists(): file_paths["ti2"] = ti2
     if ti1.exists(): file_paths["ti1"] = ti1
     for tiff in find_tiff_pages(target): file_paths[f"tiff_{i}"] = tiff
     ti3 = meas_page.get_current_ti3_path()
     if ti3 and ti3.exists(): file_paths["ti3"] = ti3
     file_paths["icc"] = icc_path
     ```
   - Call `SimpleSessionController.save(workspace=target.parent, target_name=target.name, file_paths=file_paths)`.
   - This creates/overwrites `{target_name}.wsp` in the target directory.

3. Optionally, also auto-save after `measurementsComplete` (in `_on_measurements_complete`) with the same files minus `.icc`. This gives users a `.wsp` even if they haven't created the profile yet. The post-profile auto-save will simply overwrite it.
