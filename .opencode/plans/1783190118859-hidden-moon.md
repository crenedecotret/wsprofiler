# Plan: Optimise Subsection Navigation

## Overview

Add three indented sub-items (Generate, Measure, Profile) under "Optimise" in the wizard sidebar using `QTreeWidget`. Refactor `OptimisePage`'s internal state machine to split the monolithic `STATE_READY` into separate generate/profile pages. Navigation between sub-steps is driven by clicking sidebar items.

```python
def _on_tree_item_changed(self, current: QTreeWidgetItem, _prev) -> None:
    if self._suppress_tree_signal or current is None:
        return
    # Save if leaving main Measure page
    if self._prev_step_index == 1:
        self.save_session_state()

    parent = current.parent()
    if parent is None:
        # Top-level item
        title = current.text(0)
        idx = list(self._pages.keys()).index(title)
        self._prev_step_index = idx
        self.stack.setCurrentIndex(idx)
        if title == "Optimise":
            opt = self._pages["Optimise"]
            default = opt.get_default_sub_step()
            opt.go_to_sub_step(default)
            self._select_opt_child(default)
        else:
            self._refresh_page_for_step(idx)
    else:
        # Child item under Optimise
        sub_idx = current.data(0, Qt.UserRole)
        self._prev_step_index = 3  # Optimise is always index 3
        self.stack.setCurrentIndex(3)
        self._pages["Optimise"].go_to_sub_step(sub_idx)
```

### 2f. Add sub-step public API
```python
SUB_GENERATE = 0
SUB_MEASURE = 1
SUB_PROFILE = 2

def go_to_sub_step(self, sub_idx: int) -> None:
    if sub_idx == self.SUB_GENERATE:
        state = self.STATE_GENERATE
    elif sub_idx == self.SUB_MEASURE:
        state = self.STATE_MEASURE
    elif sub_idx == self.SUB_PROFILE:
        state = self.STATE_PROFILE
    else:
        return
    self._go_to_state(state)

def get_default_sub_step(self) -> int:
    if not self.has_data():
        return self.SUB_GENERATE
    if not self._optimisation_passes:
        return self.SUB_GENERATE
    last = self._optimisation_passes[-1]
    if last.get("icc"):
        return self.SUB_GENERATE  # pass complete, ready for next
    if last.get("ti3"):
        return self.SUB_PROFILE   # measured, ready to build
    if last.get("ti2"):
        return self.SUB_MEASURE   # chart generated, ready to measure
    return self.SUB_GENERATE

def sub_step_available(self, sub_idx: int) -> bool:
    if not self.has_data():
        return False
    if sub_idx == self.SUB_GENERATE:
        return self._proc is None  # not during generation
    if sub_idx == self.SUB_MEASURE:
        if not self._optimisation_passes:
            return False
        last = self._optimisation_passes[-1]
        return last.get("ti2") is not None and last.get("ti3") is None
    if sub_idx == self.SUB_PROFILE:
        if not self._optimisation_passes:
            return False
        last = self._optimisation_passes[-1]
        return last.get("ti3") is not None
    return False
```

## Key Design Decisions

1. **QTreeWidget** over QListWidget — native tree support, identical `flags()` API, `setRootIsDecorated(False)` hides arrows
2. **Sub-step names**: Generate, Measure, Profile (same as main steps, differentiated by indentation)
3. **STATE_GENERATE_DONE**: New state for post-generation success message, separate from MEASURE
4. **Signal guard** (`_suppress_tree_signal`): Prevents infinite recursion when `subStepTransition` → `_select_opt_child` → `currentItemChanged` → handler
5. **Transient states stay in their sub-step**: GENERATING stays under Generate, BUILDING stays under Profile
6. **MeasurementPage stays in OptimisePage stack**: No change to where it lives; sidebar navigation just switches to it
