# Plan: Standard Save Location for Two-Step Wizard Session Files

## Objective
Default the two-step wizard's **Save Session** and **Resume Session** dialogs to a cross-platform standard location, while still allowing the user to override.

## Recommended Standard Location
Use `QStandardPaths.writableLocation(QStandardPaths.AppDataLocation)` with a `sessions` subdirectory:
- **Linux**: `~/.local/share/wsprofiler/sessions/`
- **Windows**: `%LOCALAPPDATA%\wsprofiler\sessions\`
- **macOS**: `~/Library/Application Support/wsprofiler/sessions/`

Rationale: `AppDataLocation` is the idiomatic Qt path for application-specific data. The app name (`wsprofiler`) and organization name are already set in `app.py`, so `QStandardPaths` resolves correctly. Session files are internal working data rather than user documents, making AppData more appropriate than Documents.

## Files to Modify

### 1. `wsprofiler/ui/two_step_dialog.py`
Add a helper method `_default_session_dir()` that:
1. Queries `QStandardPaths.writableLocation(QStandardPaths.AppDataLocation)`.
2. Appends `sessions`.
3. Creates the directory if it does not exist.
4. Falls back to `self.workspace` if the standard path is empty or creation fails.

Modify `_do_save_session()`:
- Replace `default_dir = str(Path(target_text).parent) if target_text else str(self.workspace)` with logic that:
  1. Checks `QSettings` key `last_session_dir`.
  2. If present and valid, uses it.
  3. Otherwise falls back to `_default_session_dir()`.
- Keep the existing default filename logic (`<target_stem>.wsp2` or `session.wsp2`).
- After a successful save, store the chosen directory in `QSettings` under `last_session_dir`.

Modify `_on_resume_session()`:
- Replace `str(self.workspace)` with the same fallback chain (`last_session_dir` → `_default_session_dir()` → `self.workspace`).

### 2. `wsprofiler/app.py`
No changes needed. `app.setApplicationName("wsprofiler")` and `app.setOrganizationName("wsprofiler")` are already set, which `QStandardPaths` depends on.

## Implementation Details
- **Directory creation**: Use `Path.mkdir(parents=True, exist_ok=True)` when resolving the default location.
- **Persistence**: Use `QSettings("wsprofiler", "wsprofiler")` (same as existing settings usage elsewhere).
- **Backward compatibility**: If the standard path is unavailable, fall back to `self.workspace` (current behavior).
- **Override support**: The dialog remains a `QFileDialog`, so the user can freely navigate elsewhere.

## Verification
1. Run the application (`python -m wsprofiler`).
2. Open the two-step wizard.
3. Click **Save Session** (or generate a chart and then click Save Session).
4. Verify the dialog defaults to the platform-specific standard path (e.g., `~/.local/share/wsprofiler/sessions` on Linux).
5. Save a session, then click **Resume Session** and verify it defaults to the same directory.
6. Override the location during save, close the app, reopen, and verify the next save defaults to the overridden location (via `last_session_dir`).
7. Run existing tests (`pytest`) to ensure no regressions.
