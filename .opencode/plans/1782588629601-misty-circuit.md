# Plan: Persist Wizard Defaults (Device, Paper Size, Double Density, Suppress Clipboard)

## Overview
Add QSettings-based persistence for four generate-page settings so they become the default on the next app launch for both the regular wizard and the two-step wizard.

Settings to persist:
- `wizard/last_device` – instrument code (`"i1"`, `"3p"`, `"CM"`)
- `wizard/last_paper` – paper code (`"A4"`, `"Letter"`, etc.)
- `wizard/last_double_density` – bool (ColorMunki `-h`)
- `wizard/last_no_border` – bool (i1Pro `-L` / "suppress clipboard")

Both wizards read from the same QSettings keys. The values are saved when the user clicks **Generate** in either wizard.

## Files to Modify
1. `wsprofiler/ui/pages/generate_page.py`

## Detailed Changes

### 1. `wsprofiler/ui/pages/generate_page.py`
**QSettings is already imported** (`from PySide6.QtCore import QProcess, QSettings, Qt, Signal`).

#### a. Restore defaults in `__init__`
After the UI controls are created and wired (around line 289), before `_on_instrument_changed()` is called, read QSettings and apply them:

```python
settings = QSettings()
last_device = settings.value("wizard/last_device")
if last_device:
    idx = self.instrument_combo.findData(last_device)
    if idx >= 0:
        self.instrument_combo.setCurrentIndex(idx)

# Ensure visibility toggles run before we try to restore paper/checkboxes
self._on_instrument_changed()

last_paper = settings.value("wizard/last_paper")
if last_paper:
    idx = self.paper_combo.findData(last_paper)
    if idx >= 0:
        self.paper_combo.setCurrentIndex(idx)

# Read as strings "true"/"false" (QSettings returns str for bools on some platforms)
last_dd = settings.value("wizard/last_double_density")
if last_dd is not None:
    self.double_density_check.setChecked(str(last_dd).lower() == "true")
last_nb = settings.value("wizard/last_no_border")
if last_nb is not None:
    self.no_border_check.setChecked(str(last_nb).lower() == "true")
```

Remove the existing call to `self._on_instrument_changed()` at line 298 (it is now called inside the restore block above).

#### b. Save defaults in `_on_generate`
At the top of `_on_generate` (after input validation, before queuing steps), save the current values:

```python
settings = QSettings()
settings.setValue("wizard/last_device", self.instrument_combo.currentData())
settings.setValue("wizard/last_paper", self.paper_combo.currentData())
settings.setValue("wizard/last_double_density", self.double_density_check.isChecked())
settings.setValue("wizard/last_no_border", self.no_border_check.isChecked())
```

## Edge Cases Handled
- If the saved device code no longer exists in the combo, the hardcoded default is kept.
- If the saved paper is not available for the restored device (e.g. `"4x6"` filtered out for ColorMunki), `findData` returns -1 and the device's default paper is kept.
- `QSettings` bool values may be returned as strings on some platforms; both forms are handled with `str(val).lower() == "true"`.
