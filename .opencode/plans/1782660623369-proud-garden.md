# Refactor: Session Manager, Temp Directories, and Remove Manual ti1/ti3 Loading

## Goal
Refactor wsprofiler so that:
1. "Profile folder/name" on GeneratePage becomes **only** the final ICC destination path.
2. All intermediate working files live in a **temporary directory** during the wizard.
3. The WSP session archive is **auto-saved progressively** (after Generate, Measure, Profile, Optimise).
4. The initial WSP is created on the first "Generate" click, unless resuming from an existing WSP.
5. A simple `SessionManager` orchestrates temp dirs, WSP paths, and auto-save.
6. Users can **no longer manually load .ti1 or .ti3 files** — all file loading is session-driven.

---

## 1. New `SessionManager` class

**New file:** `wsprofiler/session_manager.py`

### Responsibilities
- Own the temp working directory for the current session.
- Know the final ICC destination path (from GeneratePage).
- Know the WSP save path (auto-computed or from a loaded WSP).
- Provide file-role mappings for snapshot saving.
- Handle cleanup of orphaned temp dirs on creation.

### API sketch

```python
class SessionManager:
    def __init__(self):
        self._temp_dir: Path | None = None          # e.g. /tmp/wsprofiler_a1b2c3/
        self._wsp_path: Path | None = None          # where .wsp is saved
        self._final_icc_path: Path | None = None    # user-selected destination
        self._is_loaded: bool = False

    @property
    def working_dir(self) -> Path:
        """Return the temp directory (creating it if necessary)."""

    @property
    def target_stem(self) -> str:
        """Return a safe stem name for Argyll binaries (e.g. 'profile')."""

    def set_final_icc_path(self, path: Path) -> None:
        """Set the user-selected final ICC destination."""

    def create_new(self) -> None:
        """Create a fresh temp directory, clear any previous session."""

    def load_from_wsp(self, wsp_path: Path) -> dict[str, Path]:
        """Extract WSP to a new temp dir, set _wsp_path, return files dict."""

    def auto_save(self, file_paths: dict[str, Path], generate_config, profile_configs, optimisation_count=0) -> Path:
        """Silently save/update the WSP archive."""

    def copy_final_icc(self, source_icc: Path) -> Path:
        """Copy the generated ICC to the final destination path."""

    def cleanup(self) -> None:
        """Remove the temp directory."""
```

### Temp directory strategy
- Use `tempfile.mkdtemp(prefix="wsprofiler_")` for the working directory.
- On `create_new()`, call `_cleanup_old_sessions()` first: scan the system temp dir for `wsprofiler_*` directories older than 7 days and remove them.
- If the user clicks **Generate** while a session already exists and it was **not loaded from WSP**, call `cleanup()` on the old session first (the user confirmed: "tmp folder should be cleared if we start working on a new profile").

### WSP path strategy
- **New session:** default to `QStandardPaths.writableLocation(QStandardPaths.AppDataLocation) / "wsprofiler" / "sessions" / {stem}.wsp`. Create the directory if needed. Use an auto-increment suffix if a collision exists (reuse `_auto_increment_path`).
- **Loaded session:** set `_wsp_path` to the original file path; auto-save overwrites it in place.
- `auto_save()` delegates to `SimpleSessionController.save(workspace=temp_dir, target_name="session", target_wsp=self._wsp_path, ...)`. Using `target_name="session"` keeps the internal zip paths flat and predictable.

## 2. `GeneratePage` changes

**File:** `wsprofiler/ui/pages/generate_page.py`

### UI changes
- Rename label `"Profile folder/name:"` → `"ICC profile destination:"`.
- Change the browse dialog in `_browse_target()` from `getSaveFileName` with `"All files (*)"` to a dialog that filters for `"ICC profiles (*.icc *.icm);;All files (*)"`. Default the filename to `mytarget.icc`.
- Store the raw destination path (including `.icc` if the user typed it). The page can strip it internally when needed for stem calculation.
- Keep `get_generate_config()` but change the `"target_path"` value to store the **final ICC destination** path instead of the working stem.

### Generation logic changes
- `_on_generate()` currently validates `target.parent.exists()` and sets `self._work_dir = str(target.parent)`. 
- Instead, the page should **no longer use the target parent as the working directory**. It will emit the user's chosen final destination, and the **Wizard/SessionManager** will decide where to actually run `targen`/`printtarg`.
- However, to keep page-level tests working and avoid over-complicating the process runner, the page can accept a `working_dir` parameter or the Wizard can temporarily set the target edit to the session temp dir during generation.
  - **Simpler approach:** add a `set_working_directory(path)` method to `GeneratePage`. The Wizard calls this before `trigger_generate()` with the SessionManager's `working_dir`. The page runs Argyll in that directory but still emits the user's chosen final destination via `chartGenerated`.
- `generated_target_path` property: keep it, but now it returns the **final ICC destination** (the value from the line edit), not the working stem.

## 3. `Wizard` changes

**File:** `wsprofiler/ui/wizard.py`

### New member
```python
self._session = SessionManager()
```

### Flow: New profile
1. User clicks **Generate** on `GeneratePage`.
2. Wizard intercepts (or GeneratePage emits a signal that the Wizard handles):
   - If not `_session.is_loaded`: `_session.create_new()` (clears old temp, creates new temp dir).
   - `_session.set_final_icc_path(gen_page.final_icc_destination)`.
   - `gen_page.set_working_directory(str(_session.working_dir))`.
   - `gen_page.trigger_generate()`.
3. On `chartGenerated(ti2_path)`:
   - `_pending_ti2 = ti2_path` (this is already in the temp dir).
   - `_session.auto_save(...)` with the current files (ti1, ti2, tiffs).
   - Switch to Measure page.
4. On `measurementsComplete(ti3_path)`:
   - `_session.auto_save(...)` now including ti3.
   - Show completion dialog, offer Profile page.
5. On `profileGenerated(icc_path)`:
   - `_session.copy_final_icc(icc_path)` → copies to the user's chosen destination.
   - `_session.auto_save(...)` including the icc.
   - Feed data to OptimisePage.
6. On `optimisationComplete(icc_path)`:
   - `_session.copy_final_icc(icc_path)`.
   - `_session.auto_save(...)` with all optimisation pass files.

### Flow: Load existing WSP
- Add a new method `load_wsp_session(wsp_path: Path)` to `Wizard`.
- Call `_session.load_from_wsp(wsp_path)` which returns the `files` dict.
- Restore each page's state from the manifest:
  - `GeneratePage`: restore generate_config (device, paper, etc.) and final ICC destination.
  - `MeasurementPage`: `load_ti2(files["ti2"])`; if `files["ti3"]` exists, it will be auto-discovered.
  - `ProfilePage`: `set_ti3_path(files["ti3"])`; restore profile_config if available.
  - `OptimisePage`: call `set_original_pass_data()` or `load_wsp_session()` equivalent.
- Set the Wizard sidebar to the furthest completed step (e.g. if ti3 exists but no icc, go to Profile).

### Page wiring changes
- `_on_step_changed` no longer needs special ti2/ti3 loading logic because the files are already in place in the temp dir and pages have been pre-configured during WSP load.
- Keep `_pending_ti2` for the normal Generate→Measure flow.

## 6. `OptimisePage` changes

**File:** `wsprofiler/ui/pages/optimise_page.py`

### Remove manual WSP loading
- **Remove** `self._load_btn` and `_on_load_wsp()` from the `STATE_NO_DATA` page.
- The `STATE_NO_DATA` page should now simply say: `"No profile data loaded.\n\nComplete a full profile first (Generate → Measure → Profile)."` without any load button.
- **Remove** `load_wsp_session()` method (or make it private/internal, used only by Wizard during session restore).
- Keep `_default_session_dir()` — it may still be useful for "Save Session As..." dialogs.

### Pass target stem
- `_pass_target_stem()` currently uses `self._generate_config.get("target_path", ...)`. Since `target_path` will now store the final ICC destination, we need a different way to compute optimisation stems inside the temp dir.
- Change to: `return self.workspace / f"session_opt{pass_num}"` (where `self.workspace` will be set to the SessionManager's temp dir by the Wizard).
- Better: add `set_workspace(path)` to OptimisePage so the Wizard can tell it where to generate add-on files.

## 8. `session_controller.py` & `session.py` changes

### `SimpleSessionController.save()`
- Already supports `target_wsp` parameter — no changes needed.
- Keep the default `workspace / f"{target_name}.wsp"` behavior for backward compat; SessionManager will always pass an explicit `target_wsp`.

### `SimpleSessionController.load()`
- No changes needed — it already extracts to an `output_dir`.
- SessionManager will pass a temp dir as `output_dir`.

### Snapshot format
- Keep `SimpleSnapshot` format unchanged for backward compatibility.
- The `target_name` field will still exist but will now reflect the session stem (e.g. `"session"`) rather than the user's profile name. The user's chosen final ICC destination should be stored inside `generate_config["target_path"]`.

## 9. Backward compatibility

### Loading old WSP files
- Old `.wsp` files store `target_name` as the working stem (e.g. `"mytarget"`), and files are relative to `workspace`.
- When loading an old WSP, `SessionManager.load_from_wsp()` should:
  1. Extract to a new temp dir.
  2. Read the manifest.
  3. Derive the final ICC destination from `generate_config.get("target_path")` if present; if not, derive from `target_name` + `.icc` in the original workspace.
  4. Populate pages as normal.

### Tests
- Update `test_session.py` and `test_session_integration.py` if they assume specific path structures.
- Add tests for `SessionManager`:
  - `test_create_new_clears_old_temp()`
  - `test_auto_save_to_default_location()`
  - `test_load_from_wsp_extracts_to_temp()`
  - `test_copy_final_icc_creates_destination_parent_dirs()`

## 11. Verification steps

1. **Run the app:** `python -m wsprofiler`
2. **New session flow:**
   - Fill in GeneratePage with a final ICC path like `/home/user/Desktop/myprinter.icc`.
   - Click Generate. Verify that:
     - A temp dir is created (`/tmp/wsprofiler_*`).
     - `.ti1`, `.ti2`, and `.tiff` files appear in the temp dir, NOT next to the ICC destination.
     - A `.wsp` file is auto-saved to the app data location.
   - Proceed through Measure and Profile. Verify that:
     - `.ti3` and `.icc` are created in the temp dir.
     - The `.icc` is **copied** to `/home/user/Desktop/myprinter.icc`.
     - The `.wsp` is updated after each step.
3. **Load session flow:**
   - Click "Load Session…", choose the `.wsp` from step 2.
   - Verify the wizard resumes at the correct step with all data intact.
4. **No manual file loading:**
   - Verify MeasurementPage has no "Load Chart" button.
   - Verify ProfilePage has no "Browse…" button for .ti3.
   - Verify OptimisePage has no "Load .WSP Session…" button.
5. **Run tests:** `pytest` — all existing tests should pass (or be updated if they test removed UI elements).
