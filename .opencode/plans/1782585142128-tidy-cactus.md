# Plan: Add i1Pro No-Border (-L) Option + ColorMunki Double-Density in Wizard

## Goal
1. Add a checkbox to suppress the left paperclip border (`printtarg -L`) for the i1Pro device (`"i1"`), similar to the existing "Double density" checkbox for ColorMunki. This affects patch counts per page, so they must be recalculated per paper size.
2. Add the **missing double-density (`-h`) checkbox for ColorMunki** to the Two-Step Wizard (it already exists on the standalone Generate page but was never added to the wizard).

Both checkboxes will appear on the **standalone Generate page** and the **Two-Step Wizard**.

## Empirical Patch Counts (i1Pro with `-L`)
Measured by running `targen -f2000` + `printtarg -v -ii1 -t300 -p<PAPER> -L`:

| Paper   | Without `-L` | With `-L` |
|---------|-------------|-----------|
| A4      | 441         | 504       |
| A4R     | 512         | 560       |
| A3      | 672         | 735       |
| A2      | 987         | 1050      |
| Letter  | 462         | 504       |
| LetterR | 480         | 512       |
| Legal   | 462         | 504       |
| 4x6     | 80          | 100       |
| 11x17   | 630         | 672       |
| A3+     | 1155        | 1218      |

## Files to Modify

### 1. `wsprofiler/ui/pages/generate_page.py`
- **Extend `_PATCHES_PER_PAGE` key** from `(instrument, paper, double_density)` to `(instrument, paper, double_density, no_border)`:
  - Update all 18 existing entries to add `no_border=False`.
  - Add 10 new entries for `("i1", <paper>, False, True)` with the measured values above.
- **Add UI checkbox** `no_border_check` (label: `"Suppress left paperclip border (-L, i1Pro only)"`):
  - Place it immediately after `double_density_check` in the form layout.
  - Default: unchecked.
  - Hidden by default; shown only when `instrument == "i1"`.
- **Update `_on_instrument_changed`** to toggle visibility of `no_border_check` for `instrument == "i1"`.
- **Update `_calc_patches`** to compute `nb = no_border_check.isChecked() and instrument == "i1"` and use the 4-tuple key.
- **Update `_build_printtarg_args`** to append `"-L"` when `nb` is true.
- **Update `_refresh_preview`** to use the 4-tuple key for patch count lookup.
- **Wire signals**: connect `no_border_check.toggled` to `_refresh_preview`.

### 2. `wsprofiler/ui/two_step_dialog.py`
- **Add UI checkboxes** in `_setup_generate_page`, placed after the paper combo:
  - `_dd_check`: `"Double density (-h, ColorMunki only)"` — default checked, hidden unless `instrument == "CM"`.
  - `_no_border_check`: `"Suppress left paperclip border (-L, i1Pro only)"` — default unchecked, hidden unless `instrument == "i1"`.
- **Update `_update_paper_options`** to also toggle visibility of both checkboxes based on instrument selection.
- **Update `_refresh_summary`** to compute `dd` and `nb` from checkbox states and use the 4-tuple key.
- **Update `_on_generate`**:
  - Read `dd` and `nb` from checkboxes.
  - Use 4-tuple key for patch count lookup.
  - Append `"-h"` to `printtarg_args` when `dd` is true.
  - Append `"-L"` to `printtarg_args` when `nb` is true.
  - Save `_dd` and `_nb` states alongside `_device` and `_paper`.
- **Update `_on_precond_done`** (chart 2 generation):
  - Retrieve saved `_dd` and `_nb` states.
  - Use 4-tuple key for patch count lookup.
  - Append `"-h"` / `"-L"` to `printtarg_args` when applicable.
- **Update `snapshot`** to persist both checkbox states into `GenerateState`.
- **Update `apply_snapshot`** to restore both checkbox states from `GenerateState`.
- Update the `PATTERS_PER_PAGE_RAW` type annotation to reflect the 4-tuple key.

### 3. `wsprofiler/session.py`
