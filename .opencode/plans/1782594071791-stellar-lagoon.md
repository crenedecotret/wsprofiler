# Plan: Restrict Back Navigation and Add Auto-Save to Two-Step Wizard

## Goal
1. Prevent users from navigating BACK from Measure-First-Chart to Generate-First-Chart when the wizard was started by loading a saved session.
2. Automatically save session progress as the user advances through the wizard.

## Files to Modify
- `wsprofiler/ui/two_step_dialog.py`
- `wsprofiler/ui/session_controller.py`

## Implementation Details

### 1. Track session origin path (`two_step_dialog.py`)
- Add `self._session_path: Optional[Path] = None` in `__init__`.
- This attribute stores the `.wsp2` file path when:
  - A session was loaded via `SessionController.resume()` (see #5 below), OR
  - A fresh session was saved for the first time via auto-save/manual save.

### 2. Block Back button when session was loaded (`two_step_dialog.py`)
- In `_update_buttons()`:
  - When `idx == PAGE_MEASURE1`, hide the Back button if `self._session_path is not None`.
- In `_on_back()`:
  - Skip the `PAGE_MEASURE1 → PAGE_GENERATE` transition when `self._session_path is not None`.
  - The `PAGE_MEASURE2 → PAGE_MEASURE1` back navigation remains allowed regardless.

### 3. Refactor save methods to support silent auto-save (`two_step_dialog.py`)
Extract reusable helpers from the existing `_do_save_session()` flow:
- `_prompt_for_session_path() -> Optional[Path]`
  - Builds default filename from target text, opens `QFileDialog.getSaveFileName`, returns chosen `Path` or `None`.
- `_save_to_path(path: Path, show_confirmation: bool = False) -> bool`
  - Calls `SessionController.save(self, path)`.
  - On success: sets `self._session_path = saved_path`, updates `last_session_dir` in `QSettings`, and shows a confirmation `QMessageBox` only when `show_confirmation=True`.
  - Returns `True` if saved successfully.
- Update `_do_save_session()` to use these helpers (disconnect measurement signals, prompt, save with confirmation).

### 4. Add auto-save trigger (`two_step_dialog.py`)
- Add `_auto_save() -> None`:
  - If `self._session_path` is set → call `_save_to_path(self._session_path, show_confirmation=False)` silently.
  - If `self._session_path` is `None` and `_auto_save_prompted` is not set → set `_auto_save_prompted = True`, call `_prompt_for_session_path()`, and if the user chooses a path, call `_save_to_path(path, show_confirmation=False)`.
  - If the user cancels the prompt, `_session_path` stays `None` and we will not prompt again for this dialog instance.
- Invoke `_auto_save()` at the end of each milestone completion handler:
  - `_on_generate_done()` — after first chart generation completes.
  - `_on_meas1_complete()` — after first chart measurement completes.
  - `_on_chart2_printtarg_done()` — after second chart generation completes (end of auto1).
  - `_on_meas2_complete()` — after second chart measurement completes.
  - `_on_final_profile_done()` — after final profile is created.

### 5. Set session path on resume (`session_controller.py`)
- In `SessionController.resume()`:
  - After creating the dialog (`dialog = TwoStepWizardDialog(...)`), set `dialog._session_path = path` before returning it.
  - This marks the dialog as "loaded from session" so the Back button restriction and silent auto-save apply immediately.

## Verification
1. **Back button restriction**:
   - Start the app, open the Two-Step Wizard, generate a chart, measure it. Verify the Back button is still visible (fresh session).
   - Save the session, close the wizard, then load the saved session. Verify on the Measure-First-Chart page that the Back button is hidden.
   - Verify that from Measure-Second-Chart, Back still goes to Measure-First-Chart.

2. **Auto-save on loaded session**:
   - Load a saved session and advance through the wizard (e.g., complete measurement 1, let auto1 run, etc.).
   - Check that the original `.wsp2` file’s modification time updates after each milestone without showing a dialog.

3. **Auto-save on fresh session**:
   - Start a fresh wizard, generate the first chart. A "Save Session" prompt should appear for the first auto-save.
   - Choose a path. Subsequent milestones should silently overwrite that same file.
   - If you cancel the first prompt, no further prompts should appear (manual Save still works).

4. **Manual save still works**:
   - Click "Save Session…" at any point. It should still show the file dialog and success message.

5. **Run existing tests**:
   - `pytest` should pass with no regressions.
