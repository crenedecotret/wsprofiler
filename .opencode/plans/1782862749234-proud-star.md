# Session Manager Dialog

## Goal
Replace the existing `QFileDialog`-based "Load Session…" button with a **Session Manager** dialog that lists saved `.wsp` sessions, shows metadata, and lets the user load or delete sessions.

## Design Choices

### Why a `QTableWidget` instead of a custom model?
The codebase currently uses only convenience widgets (`QListWidget`, `QComboBox`, etc.) and has **no** `QAbstractTableModel` / `QTableView` usage. A `QTableWidget` keeps the implementation simple, consistent with existing patterns, and avoids introducing model-view boilerplate for a read-only list of ~dozens of items.

### Why read manifests without extracting?
To populate the list we only need the JSON `manifest.json` inside each `.wsp` zip. We will add a lightweight `read_manifest(path)` helper to `session.py` that opens the zip, reads the manifest, and returns the dict. This avoids writing to disk and is much faster for a listing dialog.

### Step inference logic
`.wsp` files contain a `files` dict and `optimisation_count`. We derive the step label as follows:
1. No `ti2` key → **Generate chart**
2. Has `ti2`, no `ti3` → **Read chart**
3. Has `ti3`, no `icc` → **Generate profile**
4. Has `icc`, `optimisation_count == 0` → **Complete profile**
5. Has `icc`, `optimisation_count > 0` → **Optimised profile**

This mirrors the existing `load_wsp_session` step-jump logic in `wizard.py`.

### Profile name display
`target_name` from the manifest is always present and is the stem used for Argyll binaries. We display `target_name` as the profile name. Optionally, if `profile_configs` exists and has a `description`, we can append it in parentheses.

### Sort order
Most-recent-first, parsed from `generated_at` ISO timestamp.

### Dialog result pattern
Consistent with `ChartReadDialog`: subclass `QDialog`, call `exec()`, then read `selected_path` from the instance. `selected_path` is `None` if the user cancelled or closed the dialog.

## Implementation Plan

### 1. Add `read_manifest` helper (`wsprofiler/session.py`)
- Add a new function `read_manifest(path: Path) -> dict[str, Any]` that opens the zip and returns the parsed JSON dict from `manifest.json`.
- Wrap in `try/except` so corrupt zips or missing manifests return an empty dict / raise a clear error. The caller will skip unreadable files.

### 2. Create `SessionManagerDialog` (`wsprofiler/ui/session_manager_dialog.py`)
- **Class**: `SessionManagerDialog(QDialog)`
- **Constructor**: `__init__(self, sessions_dir: Path, parent=None)`
- **Layout**:
  - `QVBoxLayout` root with 20px margins, 12px spacing (same as `ChartReadDialog`)
  - Title label: "Saved Sessions" (styled `font-size: 20px; font-weight: 600;`)
  - `QTableWidget` with 4 columns: Filename | Saved At | Step | Profile Name
    - `setSelectionBehavior(QAbstractItemView.SelectRows)`
    - `setSelectionMode(QAbstractItemView.SingleSelection)`
    - `horizontalHeader().setStretchLastSection(True)`
    - `setAlternatingRowColors(True)`
  - Empty-state `QLabel` (hidden by default): "No saved sessions found."
  - Button row `QHBoxLayout` with `addStretch()`:
    - `Load` (default button, disabled when no selection)
    - `Delete` (disabled when no selection)
    - `Cancel`
- **Methods**:
  - `_scan_sessions()`: scan `sessions_dir` for `*.wsp`, read manifest with `read_manifest`, build table rows, sort by `generated_at` descending.
  - `_get_step_label(manifest: dict) -> str`: implement inference logic above.
  - `_get_profile_name(manifest: dict) -> str`: return `target_name` or fallback to filename stem.
  - `_on_selection_changed()`: enable/disable Load and Delete buttons.
  - `_on_load_clicked()`: store selected path in `self._selected_path`, call `accept()`.
  - `_on_delete_clicked()`: confirm with `QMessageBox.question`, then delete the `.wsp` file and refresh the table.
  - `_on_cancel_clicked()`: call `reject()`.
  - `selected_path() -> Path | None`: public getter.

### 3. Integrate into `Wizard` (`wsprofiler/ui/wizard.py`)
- Change button text from `"Load Session…"` to `"Session Manager"`.
- Update tooltip to `"Open the session manager to resume or delete saved sessions."`.
- Replace `_on_load_session_clicked`:
  ```python
  def _on_load_session_clicked(self) -> None:
      from .session_manager_dialog import SessionManagerDialog
      dialog = SessionManagerDialog(
          self._session.default_sessions_dir, parent=self
      )
      dialog.exec()
      selected = dialog.selected_path()
      if selected:
          self.load_wsp_session(selected)
  ```
- Remove the unused `QFileDialog` import from `wizard.py` (keep `QMessageBox`).

## Follow-up Fix: Profile Name Should Show the User's ICC Filename

### Problem
The Profile Name column currently displays `manifest["target_name"]` which defaults to `"session"` when the user hasn't yet specified a final ICC destination. The screenshot shows every row showing **session**, which is not useful.

### Root Cause
`SessionManager._target_stem` defaults to `"session"` and only gets updated when `Wizard._initialise_session()` captures the GeneratePage's `final_icc_destination`. If the user generates a chart before filling in the destination field, the auto-saved manifest stores `target_name: "session"`.

### Solution
`GeneratePage.get_generate_config()` already stores the user's chosen ICC destination path in `generate_config["target_path"]`. We should use that for the Profile Name display instead of `target_name`.

### Change Required
In `SessionManagerDialog._get_profile_name()` (`wsprofiler/ui/session_manager_dialog.py`):
- **Primary**: Check `manifest.get("generate_config", {}).get("target_path")`. If present and non-empty, return `Path(target_path).stem` (e.g. `"MyPrinter"` from `/home/user/MyPrinter.icc`).
- **Fallback 1**: `manifest.get("target_name")` (the Argyll binary stem).
- **Fallback 2**: `path.stem` (the `.wsp` filename stem).

Also update `test_profile_name` in `test_session_manager_dialog.py` to assert against `generate_config.target_path`.
