### 2c. Add `_auto_save_after_opt_generate` helper

```python
def _auto_save_after_opt_generate(self) -> None:
    opt_page = self._pages["Optimise"]
    file_paths = self._collect_optimisation_files(opt_page)
    self._session.auto_save(
        file_paths=file_paths,
        generate_config=opt_page._generate_config,
        profile_configs=list(opt_page._profile_configs),
        optimisation_count=len(opt_page._optimisation_passes),
        measurement_complete=self._measurement_complete,
    )
```

## Auto-Save Summary

| Event | `optimisation_count` | `profile_configs` | Notes |
|-------|---------------------|-------------------|-------|
| Opt chart generated | `len(_optimisation_passes)` = 1 | `[original_config]` | Pass has ti1+ti2 |
| Opt measurement stopped | via `save_session_state()` | same | Partial state |
| Opt measurement complete | `len(_optimisation_passes)` = 1 | `[original_config]` | Pass has ti1+ti2+ti3 |
| Opt profile done | `len(_optimisation_passes)` = 1 | `[original_config, opt_config]` | Pass complete |
