# Plan: Copy TIFFs to ICC destination and list them in the print dialog

## Goal
When chart generation finishes, copy the resulting TIFF files out of the temp `/tmp` directory into the ICC profile destination folder. Replace the current generic folder-path dialog with a precise list of files that need to be printed, rendering each filename in a yellow-ish colour (`#D4A76A`, the theme semantic `WARNING` colour).

Apply the same behaviour to **both** the initial chart generation and every optimisation pass chart generation.

## Files to modify

1. `wsprofiler/ui/wizard.py`
2. `wsprofiler/ui/pages/optimise_page.py`

## Implementation details

### 1. `wsprofiler/ui/wizard.py`

- **Add import**: `import shutil` (not currently imported).
- **Extract reusable helper** `_show_print_dialog(ti2_path: Path, title: str = "Charts Ready for Printing") -> None`:
  - Call `find_tiff_pages(ti2_path)` to discover the exact `_p*.tiff` files.
  - Resolve the destination directory from `self._session.final_icc_path.parent` (if `final_icc_path` is set). Fall back to `ti2_path.parent` when unset.
  - Create the destination directory if it does not exist (`mkdir(parents=True, exist_ok=True)`).
  - Copy each TIFF with `shutil.copy2(src, dest_dir / src.name)`.
  - Build a rich-text `QMessageBox` (`msg.setTextFormat(Qt.TextFormat.RichText)`).
  - Dialog text:
    - Folder path in the normal text colour.
    - Each filename wrapped in `<span style="color:#D4A76A;">` on its own line.
    - Keep the existing printing instructions and bullet points (using `<br>` because rich text is enabled).
  - Show the modal with a single **OK** button.
- **Update `_on_chart_generated`**:
  - Keep the existing `_auto_save_after_generate(ti2_path)` call.
  - Replace the inline `QMessageBox` construction with a call to `self._show_print_dialog(ti2_path)` when `not self._suppress_dialogs`.
- **Add new signal handler for optimisation passes**:
  - In `__init__`, connect `self._pages["Optimise"].passChartsGenerated` to a new slot `self._on_pass_charts_generated`.
  - Implement `_on_pass_charts_generated(self, ti2_path: Path, pass_num: int) -> None`:
    - If `not self._suppress_dialogs`, call `self._show_print_dialog(ti2_path, title=f"Optimisation Pass {pass_num} — Charts Ready for Printing")`.

### 2. `wsprofiler/ui/pages/optimise_page.py`

- **Add new signal** near the existing `optimisationComplete` signal:
  ```python
  passChartsGenerated = Signal(Path, int)
  ```
- **Emit the signal** at the end of `_on_printtarg_done` (after the pass data is stored and before switching to measurement):
  ```python
  self.passChartsGenerated.emit(ti2_path, self._pending_pass_num)
  ```

## Edge cases handled

- **No TIFF files found**: the helper will detect an empty list and show a simple fallback message (defensive, though `printtarg` always produces at least one page on success).
- **Unset ICC destination**: falls back to the temp folder (same as today) so the wizard never blocks the user.
- **Destination directory does not exist**: created on demand with `mkdir(parents=True, exist_ok=True)`.
- **File collisions**: `shutil.copy2` overwrites existing files, which is acceptable because these are freshly generated charts.
